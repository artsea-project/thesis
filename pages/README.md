# Strony formalne

Przed złożeniem pracy pobierz z systemu MojaPG właściwe dla autora:

1. stronę tytułową jako `1_title.pdf`,
2. oświadczenie jako `2_statement.pdf`.

Następnie odkomentuj odpowiadające im wywołania `image(...)` w `main.typ`.
Nie dodano tu kopii dokumentów ze startera, ponieważ są to jedynie strony instruktażowe i powinny zostać zastąpione dokumentami konkretnej pracy.
